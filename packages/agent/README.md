# @gasboost/agent

Apps Script agent orchestration for `@gasboost/gemini` and `@gasboost/openai`.

`AppsScriptAgent` executes registered tools, continues provider responses, and reports
tool-call status. Configure the API client for the selected provider and supply
materialized tools from `@gasboost/tool`.

See the [repository documentation](https://github.com/gasboost/ai#gemini) for examples.
